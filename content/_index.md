Hey there! I'm a cybersecurity postgraduate with a passion for solving complex security challenges from first principles. My professional experience has been all about creating robust solutions, and now I'm channeling that passion into the world of cybersecurity while pursuing an MSc in Cyber Security Management at the University of Warwick, currently on track for a Distinction. I love getting hands-on with new technologies and believe the best way to build great software is to build it securely from the start.

## My Journey 🚀

At **Oracle**, I focused on implementing robust Anti-Money Laundering (AML) solutions, where I reduced vulnerabilities by applying security controls, running SAST scans, and conducting risk audits within large-scale financial systems using technologies like Java Spring Boot and Pentaho.

In previous **startup roles**, I honed my skills in secure application development, implementing everything from input sanitisation and secure authentication (aligned with OWASP Top 10) to encrypted data transmission protocols for sensitive healthcare data.

Beyond my professional work, I am always building. I have completed over **50 hands-on labs on TryHackMe**, was named a **Black Hat Europe Scholar 2025**, and picked up wins at the PwnED and ElasticSearch CTFs. I'm currently working on my dissertation on **NLP-based Adverse Media Risk Scoring** to help combat financial fraud, alongside personal projects like **GoCyberChef** (a security tool in Go & WebAssembly) and **fREeAD** (an AI-powered RSS reader). I also serve as the **Postgraduate Representative** for the Warwick Cyber Security Society.
